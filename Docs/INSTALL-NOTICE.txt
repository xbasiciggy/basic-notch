BASICNOTCH 1.0.1 — LOCAL PREVIEW

This preview build has not been notarized by Apple. macOS may show a security warning when it is downloaded from the internet. Only install a copy from a source you trust. This notice is not a replacement for Developer ID signing and Apple notarization.

To install: open the DMG, drag BasicNotch to Applications, eject the disk image and launch the app from Applications. The sparkle menu is in the menu bar; BasicNotch has no Dock icon.

The app can request permissions for optional integrations. You can decline permissions and continue using other tools. Read the included User Guide for accounts, data providers, clipboard behavior and feature limitations.
